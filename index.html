Розділ А. Перемикачі в Python (Checkbutton)

  • Що таке перемикачі? Перемикач (прапорець) — це елемент графічного інтерфейсу користувача, який може перебувати у двох станах: увімкнений (позначений галочкою) або вимкнений.
  • Для чого використовують Checkbutton? Віджет Checkbutton бібліотеки tkinter застосовують тоді, коли користувачеві потрібно обрати один або декілька незалежних пунктів зі списку (наприклад, улюблені предмети, додаткові опції замовлення, налаштування програми).
  • Чим перемикачі відрізняються від звичайних кнопок? Звичайна кнопка (Button) лише запускає дію під час натискання і не зберігає стан вибору. Перемикач (Checkbutton) фіксує стан (0 або 1), який можна зчитати у будь-який момент.
  • Як створювати та отримувати значення? Для збереження стану створюють спеціальну цілочисельну змінну IntVar(), прив'язують її параметром variable, а поточне значення отримують методом .get().
Властивість / елемент Звичайна кнопка (Button) Перемикач (Checkbutton)
Збереження стану вибору Не зберігає (спрацьовує в момент кліку) Зберігає стан у змінній IntVar() (1 або 0)
Вибір кількох пунктів Не призначена для множинного вибору Дозволяє одночасно обрати кілька прапорців
Приклад із життя Дзвінок біля дверей Вимикач світла або список покупок із галочками

Приклад коду створення перемикача у Tkinter:

from tkinter import *

root = Tk()
root.title("Мої вподобання")

var1 = IntVar()

check = Checkbutton(
    root,
    text="Я люблю програмувати",
    variable=var1
)
check.pack()

root.mainloop()

Покрокове пояснення кожного рядка коду:

  • from tkinter import * — імпортує всі класи та функції бібліотеки Tkinter для створення віконного інтерфейсу.
  • root = Tk() — створює головне вікно програми.
  • root.title("Мої вподобання") — встановлює заголовок вікна.
  • var1 = IntVar() — створює спеціальну змінну керування для збереження цілого значення (1 або 0).
  • check = Checkbutton(root, text="Я люблю програмувати", variable=var1) — створює перемикач у вікні root із написом та пов'язує його зі змінною var1 через параметр variable.
  • check.pack() — розміщує перемикач у вікні програми.
  • root.mainloop() — запускає головний цикл обробки подій вікна.
💡 Запам'ятайте: IntVar() зберігає ціле число. Значення 1 означає, що перемикач увімкнений, а значення 0 — що перемикач вимкнений. Отримати це число можна викликом var1.get().

Розділ Б. Глобальні змінні в Python

  • Що таке змінна? Іменована область пам'яті комп'ютера, у якій зберігаються дані під час виконання програми.
  • Що таке локальна змінна? Змінна, створена всередині функції. Вона існує лише під час роботи цієї функції і недоступна за її межами (як особистий чернетковий зошит на парті учня).
  • Що таке глобальна змінна? Змінна, створена в основній частині програми (поза функціями). Її значення бачать усі функції програми (як класна дошка або спільне табло рахунку на стадіоні).
  • Для чого використовують команду global? Якщо всередині функції потрібно не просто прочитати, а змінити значення глобальної змінної, її обов'язково потрібно оголосити командою global ім_я_змінної.
Критерій Локальна змінна Глобальна змінна
Де створюється Усередині функції (def ...) У головному коді програми (поза функціями)
Де доступна Лише всередині своєї функції У всій програмі та в усіх функціях
Як змінити у функції Звичайним присвоєнням x = 5 Спочатку оголосити global x, потім змінювати

Приклад роботи з глобальною змінною:

score = 0

def add_point():
    global score
    score = score + 1

add_point()
print(score)
  • score = 0 — створює глобальну змінну score зі стартовим значенням 0 у головній частині програми.
  • def add_point(): — оголошує функцію add_point для нарахування бала.
  • global score — повідомляє Python, що всередині функції буде змінюватися саме глобальна змінна score, а не створюватися нова локальна.
  • score = score + 1 — збільшує значення глобальної змінної score на 1.
  • add_point() — викликає функцію (після цього score дорівнює 1).
  • print(score) — виводить на екран число 1.
⚠️ Головне правило: якщо функція повинна змінювати глобальну змінну, потрібно обов'язково оголосити її всередині функції за допомогою ключового слова global!
