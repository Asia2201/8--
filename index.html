Розділ А. Перемикачі в Python (Checkbutton) 🔘

Перемикач (Checkbutton) — це елемент графічного інтерфейсу Tkinter, який дозволяє користувачеві увімкнути або вимкнути певну опцію (поставити або зняти прапорець «гачок»).

Елемент Призначення Особливість
Button Виконання миттєвої дії при натисканні Не зберігає стан «увімкнено/вимкнено»
Checkbutton Вибір або скасування опції Зберігає стан (1 — увімкнено, 0 — вимкнено)

Приклад створення Checkbutton у Tkinter:

from tkinter import *

root = Tk()
root.title("Мої вподобання")

var1 = IntVar()

check = Checkbutton(
    root,
    text="Я люблю програмувати",
    variable=var1
)
check.pack()

root.mainloop()

Покрокове пояснення коду:

  • from tkinter import * — імпортуємо всі модулі бібліотеки Tkinter для створення графічного вікна.
  • root = Tk() та root.title(...) — створюємо головне вікно програми та задаємо його заголовок.
  • var1 = IntVar() — створюємо спеціальну цілочисельну змінну Tkinter для збереження стану прапорця.
  • check = Checkbutton(root, text=..., variable=var1) — створюємо віджет перемикача. Параметр variable=var1 пов'язує перемикач зі змінною var1.
  • check.pack() — розміщуємо перемикач у вікні.
💡 Головне правило: Якщо прапорець увімкнено (поставлено гачок), змінна var1.get() повертає 1. Якщо прапорець вимкнено — повертає 0.

Розділ Б. Глобальні змінні у Python 🌐

Під час написання програм із графічним інтерфейсом часто виникає потреба змінювати спільні дані (наприклад, лічильник балів або кількість очок) з різних функцій.

Тип змінної Де створюється Область видимості
Локальна змінна Усередині конкретної функції Доступна лише всередині цієї функції та зникає після її завершення
Глобальна змінна У основній програмі (поза функціями) Доступна для зчитування в усій програмі та між різними функціями

Приклад використання глобальної змінної:

score = 0  # Глобальна змінна

def add_point():
    global score     # Оголошуємо, що будемо змінювати саме глобальну змінну score
    score = score + 1

add_point()
print(score)  # Виведе: 1

Покрокове пояснення коду:

  • score = 0 — створюємо глобальну змінну score зі початковим значенням 0.
  • def add_point(): — визначаємо функцію додавання балу.
  • global score — ключова команда! Вона вказує Python, що функція має модифікувати глобальну змінну score, а не створювати нову локальну.
  • score = score + 1 — збільшуємо значення глобальної змінної на 1.
⚠️ Пам'ятай: Якщо всередині функції потрібно тільки зчитати глобальну змінну — global можна не писати. Але якщо потрібно змінити її значення (наприклад, score = score + 1), команда global score є обов'язковою!
