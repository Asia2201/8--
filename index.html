🔘 Розділ А. Перемикачі в Python (Checkbutton)

Перемикач (Checkbutton) — це елемент графічного інтерфейсу Tkinter, який дозволяє користувачеві увімкнути або вимкнути певну опцію (поставити або зняти прапорець «гачок»).

Елемент інтерфейсу Призначення Відмінність від інших
Button Виконання дії при кліку Не зберігає стан після натискання
Checkbutton Вибір або скасування опції Зберігає стан (1 — увімкнено, 0 — вимкнено)

Приклад створення Checkbutton у Tkinter:

from tkinter import *

root = Tk()
root.title("Мої вподобання")

var1 = IntVar()

check = Checkbutton(
    root,
    text="Я люблю програмувати",
    variable=var1
)
check.pack()

root.mainloop()

Покрокове пояснення коду:

  • from tkinter import * — імпортуємо бібліотеку Tkinter для створення графічних вікон.
  • root = Tk() та root.title(...) — створюємо головне вікно та додаємо заголовок.
  • var1 = IntVar() — створюємо спеціальну змінну Tkinter для збереження цілого значення.
  • check = Checkbutton(root, text=..., variable=var1) — створюємо перемикач і пов'язуємо його зі змінною var1 за допомогою параметра variable.
  • check.pack() — розміщуємо перемикач у вікні.
💡 Запам'ятай: Значення 1 означає, що перемикач увімкнений. Значення 0 означає, що перемикач вимкнений. Зчитати стан змінної можна методом var1.get().

🌐 Розділ Б. Глобальні змінні у Python

У програмах із графічним інтерфейсом виникає потреба змінювати спільні дані (наприклад, лічильник балів) з різних функцій.

Тип змінної Де створюється Область видимості
Локальна змінна Всередині функції Доступна лише всередині цієї функції
Глобальна змінна У основній програмі (поза функціями) Доступна у всій програмі та між різними функціями

Приклад зміни глобальної змінної:

score = 0  # Глобальна змінна

def add_point():
    global score     # Оголошуємо змінну як глобальну
    score = score + 1

add_point()
print(score)  # Виведе: 1

Покрокове пояснення коду:

  • score = 0 — створюється глобальна змінна поза функціями.
  • def add_point(): — створюється функція додавання балу.
  • global score — вказує Python, що всередині функції буде змінюватися саме глобальна змінна score.
  • score = score + 1 — збільшує значення глобальної змінної на 1.
⚠️ Головне правило: Якщо функція повинна змінювати глобальну змінну, необхідно оголосити її за допомогою ключового слова global!
