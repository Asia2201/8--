# Інтерактивна навчальна платформа «Використання перемикачів. Глобальні змінні в Python» (8 клас)

Повноцінний інтерактивний вебпрактикум українською мовою для учнів 8 класу з інформатики.

## Структура проєкту
- `index.html` — головний файл застосунку з усіма 8 сторінками-екранами, верхньою панеллю даних учня та навігацією;
- `css/style.css` — сучасні стилі (фіолетово-синьо-бірюзова палітра на світлому фоні), адаптивність та правила друку A4;
- `js/data.js` — теоретичні матеріали, завдання Практичної частини №1, Практичної частини №2 та Підсумкового тесту (8 запитань);
- `js/app.js` — навігація між сторінками, збереження прогресу в `localStorage`, симулятори №1 і №2, перевірка всіх завдань без повторного нарахування балів, підрахунок 36 балів, перерахунок у 12-бальну шкалу та друк звіту;
- `.nojekyll` — файл для коректної публікації статичного сайту на GitHub Pages;
- `README.md` — документація проєкту.

## Локальний запуск
1. Розпакуйте ZIP-архів у будь-яку папку.
2. Відкрийте файл `index.html` у сучасному браузері (Chrome, Edge, Firefox, Safari).

## Публікація на GitHub Pages
1. Створіть новий публічний репозиторій на GitHub.
2. Завантажте всі файли з розпакованої папки (`index.html`, `css/`, `js/`, `.nojekyll`, `README.md`) у корінь репозиторію.
3. Перейдіть у **Settings → Pages**, у блоці **Build and deployment** оберіть **Deploy from a branch**, гілку `main` та папку `/(root)`, натисніть **Save**.
4. Через 1–2 хвилини застосунок стане доступним за посиланням `https://<ваш-логін>.github.io/<назва-репозиторію>/`.
