# Практична робота з інформатики (8 клас)
## Тема: «Використання перемикачів. Глобальні змінні в Python»

Інтерактивний навчальний вебпрактикум для учнів 8 класу з багатосторінковою навігацією, двома інтерактивними симуляторами Tkinter / Python, двома практичними частинами, підсумковим тестом та автоматичним формуванням звіту для друку (A4).

### Запуск локально або на GitHub Pages
1. Розпакуйте архів у папку та відкрийте `index.html` у браузері (усі стилі та скрипти вбудовані в `index.html`, а також продубльовані у `css/` та `js/`).
2. Для публікації на GitHub Pages завантажте вміст папки у репозиторій та увімкніть **Settings → Pages → Deploy from a branch → main / (root)**.
