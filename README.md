# Навчальний практикум з інформатики для 8 класу
**Тема:** «Використання перемикачів. Глобальні змінні в Python»
**Навчальний заклад:** КЗ «Ліцей "Інтелект" Долинської міської ради»

---

## 📌 Опис проєкту
Цей інтерактивний вебсайт розроблений для проведення практичної роботи з інформатики у 8-му класі відповідно до вимог програми НУШ. Проєкт поєднує теоретичний конспект, інтерактивні симулятори Tkinter, практичні завдання з автоматичною перевіркою та генератор підсумкового звіту для друку або збереження в PDF.

---

## 🛠️ Технології
- **HTML5** — семантична розмітка вкладок та бланка звіту.
- **CSS3** — світлий сучасний дизайн (пурпурово-бірюзова палітра), гнучка адаптивність (Flexbox/Grid), стилі для друку `@media print`.
- **JavaScript (ES6)** — управління навігацією, автоматичний підрахунок 36 балів, конвертація у 12-бальну шкалу, використання `localStorage`.

---

## 📊 Система оцінювання (Максимум 36 балів)
| Навчальний блок | Максимальний бал |
| :--- | :---: |
| Теоретичний блок | 0 балів (навчальний) |
| Симулятор №1 (Checkbutton) | 2 бали |
| Симулятор №2 (Global Variables) | 2 бали |
| Практична частина №1 | 8 балів |
| Практична частина №2 | 8 балів |
| Підсумковий тест | 16 балів |
| **УСЬОГО** | **36 балів** |

**Формула підсумкової оцінки:** `Оцінка = Округлення( Набрані бали / 36 * 12 )`

## 🚀 Інструкція із запуску
1. **Локальний запуск:**
   - Завантажте та розпакуйте ZIP-архів.
   - Відкрийте файл `index.html` у будь-якому сучасному веббраузері (Chrome, Firefox, Edge, Safari).

2. **Публікація на GitHub Pages:**
   - Завантажте вміст розархівованої папки у ваш репозиторій на GitHub.
   - Перейдіть у **Settings ➔ Pages** вашого репозиторію.
   - У розділі **Build and deployment** оберіть гілку `main` (або `master`) та натисніть **Save**.
   - За 1 хвилину сайт буде опубліковано за адресою `https://<ваш_нікнейм>.github.io/<назва_репозиторію>/`.

---

## 🖨️ Особливості друку звіту
На Сторінці 8 натисніть кнопку **«Друкувати звіт / Зберегти у PDF»**. Завдяки стилям `@media print` сайт автоматично приховає всі елементи управління, шапку, кнопки та згенерує чистий A4 документ із результатами, оцінкою та місцем для підпису учня й вчителя.
